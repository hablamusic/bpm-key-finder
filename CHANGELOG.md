# Changelog

## 0.2.0 (2026-11-26)

- Web version on GitHub Pages (https://hablamusic.github.io/bpm-key-finder/, EN/ES/PT): drop files or a folder, analysis runs in the browser with the same code as the CLI; CSV export.
- README: "Start here" paths for beginners, animated terminal demo, new banner and social preview, `npx skills add` install.

## 0.1.0 (2026-11-26)

- First release: BPM (spectral-flux autocorrelation) and key (chroma + Krumhansl-Kessler) detection, Camelot and Open Key codes, compatible keys.
- CLI for files and folders with table, CSV and JSON output, sorting by BPM or Camelot.
- Native WAV decoder; other formats through ffmpeg.
- Benchmark on 19 AI-generated tracks against essentia.
- Agent skill files for Claude Code, Cursor and Codex.
